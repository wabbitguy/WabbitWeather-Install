WabbitWeather — CYD Install

Install WabbitWeather v1.8.0 on your 2.8" CYD (Cheap Yellow Display) straight from your browser. No Arduino IDE needed.

This installer needs a browser that can talk to USB serial ports: Chrome, Edge or Opera on a computer. It doesn't work in Safari, Firefox or on phones.

Not sure? Install either one. If the screen stays white or the colours look wrong, install the other.

Before you start:
  1. First time flashing a CYD on this computer? Its USB chip (CH340) may need a driver before the browser can see it — without it, the port list stays empty. Windows driver · macOS driver · Linux usually needs no driver.
  2. Connect the CYD with a USB data cable (not a charge-only one).
  3. Pick your board and language, click "Connect & Install" and choose the CYD's port.
  4. Installing erases the board, including any saved WiFi and settings, then flashes everything in one go — fonts and pictures included.
  5. When it restarts, follow the setup on the screen to connect it to your WiFi.
Need help, or want to build it yourself? See WabbitWeather on GitHub.
